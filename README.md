# Operating System Practicals in C

A collection of **Operating System practical programs implemented in C** for learning, academic preparation, and understanding core OS concepts through practical implementation.

This repository contains various Operating System algorithms and practical programs commonly included in Diploma, Engineering, and Computer Science laboratory courses.

## 📚 About

Operating Systems is one of the fundamental subjects in Computer Science and Information Technology. Understanding OS concepts becomes easier when algorithms are implemented practically.

This repository provides simple and well-structured **C language implementations** of important Operating System practicals including:

* CPU Scheduling Algorithms
* Deadlock Avoidance
* Memory Management
* Page Replacement Algorithms
* File Allocation Methods
* Disk Scheduling Algorithms
* Process Management Concepts

All programs are designed to be beginner-friendly and easy to understand.

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/iamaryan7/os-practicals.git
```

### 2. Open the Repository

```bash
cd os-practicals
```

### 3. Compile the Program

Example:

```bash
gcc fcfs.c -o fcfs
```

### 4. Run the Program

Linux/macOS:

```bash
./fcfs
```

Windows:

```bash
fcfs.exe
```

You can replace `fcfs.c` with any practical program available in the repository.
